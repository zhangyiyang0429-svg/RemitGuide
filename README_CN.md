# RemitGuide 演示使用手册

课堂演示使用虚构账户。每次只改一项，观察提示后还原，再演下一项。

## 1　启动与重置

在 feat/remittance-flow 分支的 Codespaces 终端运行以下命令。如果旧服务占用端口，先在其终端按 Ctrl+C。打开「端口」中的 8501。

```
git pull --ff-only origin feat/remittance-flow
python -m streamlit run demo.py --server.address 0.0.0.0 --server.port 8501
```

重新演示时，点左栏「清空记录」。「取消」保留全部订单，「确定清空」删除当前演示链接下的记录。重新开始时再输入并确认 23:00。

| 张三 | 18,000 | 12,000 | 24,000 |

先选付款账户，再选报价银行。换银行或收款币种都沿用同一付款账户的额度。预约成功即占用含手续费的付款总额；复核申请不占用。扣款时占用转为已用，到账退款只恢复实退余额。每个演示链接模拟一个营业日，回拨时钟不会重置额度，确认清空记录后恢复初始值。旧版无付款人字段的历史记录按张三账户计入。

### 在侧栏输入时间

使用 24 小时制输入时间，点击「确定时间」才生效。23:00 至次日 06:59 可预约并比较当小时报价；07:00–07:04 自动提交并显示订单；07:05–10:59 展示回执；11:00–22:59 保留银行回执，并在下方展示退回记录。可用 23:30、07:03、09:15、15:00 依次演示四个阶段。侧栏底部的曲线按香港时间从 23:00 至 07:00 排列，仅显示一条模拟官方参考汇率线，单位为人民币／100 港元。各行同小时报价均高于该参考值，可在核对页比较。

## 3　用一笔汇款走完整条时间线

1. 在左栏选 02:00，保留默认ZHANGSAN及海湾银行，点击「下一步 · 核对汇款」。选择报价银行时三家报价自动并列显示。
2. 海湾银行手续费 10.00 元，兑换本金 4,990.00 元，汇率 92.62，预计实收 5,387.61 港元。点击「确认预约并锁定报价」。
3. 在左栏输入并确认 07:00，打开「汇款记录」。订单显示「确认中」，付款行已扣款，收款行尚未确认到账；07:00 参考汇率为 93.10，实际仍采用 92.62。
4. 将时钟调到 07:05，页面自动展示每笔已提交交易的银行回执。所有正常订单均在此时确认到账。没有提交交易或只有待复核申请时，显示「无有效订单」。
5. 11:00 保留所有已提交订单的原回执，下方追加退回记录。所有交易都成功、从未提交订单或仅有待复核申请时，隐藏退回记录栏。预检填错后修正，按修正后的资料正常办理。
6. 演示退汇：任选收款人及币种。07:00 在「汇款记录」选择一笔确认中的订单，展开「模拟收款行通知」，点击「通知此笔交易暂停入账」。07:05 该笔显示退回原因，11:00 显示退款。其余订单按正常流程到账。

可以直接跳到 11:00，系统会补齐经过的事件。回拨后可演示另一笔夜间预约，已有交易不会重复扣款。07:05 至 11:00 为本演示的回执观察时段。

## 同名汇款与退汇回执

选择陈大文后，默认载入 CHENDAIWEN、香港银行、香港居民身份证和本人账号。改填张三的整套资料也会被拦截。收款人仅在确认到账后显示实收金额，退款在途及已退汇均显示 0.00。退汇仅扣原手续费，人民币本金全额原路退还。已结算的历史记录保留原金额。左侧按钮可切换中英文。成功回执弹窗比较锁价与 07:00 同行报价，仅显示到账差额。汇率单位为每 100 港元所需人民币，锁价不能保证多收。

选择报价银行时直接显示三行报价。Open API 按钮标示报价接口的预留位置，未连接外部银行。银行状态自动显示，仅发生退汇时展示退回记录。

提案第 5.3 节列出三个核心接口。RemitGuide Remittance Open API 位于汇款资料区，Confirmation Open API 位于预约核对区，Refund Open API 位于退回记录区。Account Profile 和 FX Quotes 是账户资料与报价辅助接口。按钮仅标示预留接入位置。

## 核心接口调用约定

三个接口在本地 Python 进程内执行。按钮用于说明接口位置，业务流程触发实际调用。

| 调用方法 | 输入 | 返回与异常 |
|---|---|---|
| remittance_precheck | 本人汇款资料、报价 | 报价编号、预检状态、修正提示；响应不含证件号、账号和地址 |
| confirm_preorder | 当前会话、付款账户、报价、预检结果 | 成功返回订单号；报价关联不符、资料受限或额度不足时不能创建可执行预约 |
| refund_settlement | 银行标记退款在途的订单 | 返回订单号、币种、退款额和保留手续费；其他状态拒绝结算。11:00 由订单时钟触发 |
