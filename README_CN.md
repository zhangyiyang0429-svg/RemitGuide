# RemitGuide 演示使用手册

## 1　启动与重置

在 feat/remittance-flow 分支的 Codespaces 终端运行以下命令。如果旧服务占用端口，先在其终端按 Ctrl+C。打开「端口」中的 8501。

```
git pull --ff-only origin feat/remittance-flow
python -m streamlit run demo.py --server.address 0.0.0.0 --server.port 8501
```

重新演示时，点左栏「清空记录」。「取消」保留全部订单，「确定清空」删除当前演示链接下的记录。重新开始时再输入并确认 23:00。

### 付款账户与转账额度（CNY）

| 付款账户 | 初始可用余额 | 单笔限额 | 每个演示日累计限额 |
| --- | ---: | ---: | ---: |
| 张三 | 18,000 | 12,000 | 24,000 |
| 陈大文 | 32,000 | 15,000 | 20,000 |
| Kevin James | 45,000 | 25,000 | 35,000 |

先选付款账户，再选报价银行。换银行、收款人或收款币种都沿用同一付款账户的额度。预约成功即占用含手续费的付款总额；复核申请不占用。扣款时占用转为已用，到账退款只恢复实退余额。每个演示链接模拟一个营业日，回拨时钟不会重置额度，确认清空记录后恢复初始值。旧版无付款人字段的历史记录按张三账户计入。

### 在侧栏输入时间

使用 24 小时制输入时间，点击「确定时间」才生效。23:00 至次日 06:59 可预约并比较当小时报价；07:00–07:04 自动提交并显示订单；07:05–10:59 展示回执；11:00–22:59 展示退汇。可用 23:30、07:03、09:15、15:00 依次演示四个阶段。侧栏底部的曲线按香港时间从 23:00 至 07:00 排列，仅显示一条模拟官方参考汇率线，单位为港元／人民币。各行同小时报价均高于该参考值，可在核对页比较。

银行账户路径填写姓名、收款行和账号；手机号路径填写姓名和八位号码。切换收款人时一并更新相应字段。付款总额默认 5,000 元，已含手续费。

## 3　用一笔汇款走完整条时间线

1. 在左栏选 02:00，保留默认ZHANGSAN及海湾银行，点击「下一步 · 核对汇款」。可勾选「比较其他可用银行」。
2. 海湾银行手续费 10.00 元，兑换本金 4,990.00 元，汇率 1.0850，预计实收 5,414.15 港元。点击「确认预约并锁定报价」。
3. 在左栏输入并确认 07:00，打开「汇款记录」。订单显示「确认中」，付款行已扣款，收款行尚未确认到账；07:00 参考汇率为 1.0750，实际仍采用 1.0850。
4. 将时钟调到 07:05，页面自动展示每笔已提交交易的银行回执。所有正常订单均在此时确认到账。没有提交交易或只有待复核申请时，显示「无有效订单」。
5. 11:00 自动进入退汇记录。所有交易都成功、从未提交订单或仅有待复核申请时，显示「无订单」。预检填错后修正，按修正后的资料正常办理。
6. 演示退汇：任选收款人及币种。07:00 在「汇款记录」选择一笔确认中的订单，展开「模拟收款行通知」，点击「通知此笔交易暂停入账」。07:05 该笔显示退回原因，11:00 显示退款。其余订单按正常流程到账。

可以直接跳到 11:00，系统会补齐经过的事件。回拨后可演示另一笔夜间预约，已有交易不会重复扣款。07:05 至 11:00 为本演示的回执观察时段。

## 4　逐项改错演示表

以下以默认ZHANGSAN资料为起点，涉及其他收款人的行请先填好其完整资料。地址编辑后按 Enter 或点出输入框；其余项目改完点「下一步 · 核对汇款」。每条提示对应当前界面能够触发的一类结果。

| 改动示例 | 可观察的结果 |
| --- | --- |
| 清空登记地址；或将 Chinese Hill 改为「中文山」 | 请检查地址格式；下一步禁用 |
| 把英文逗号改为中文逗号，去掉逗号后的空格，或加两个空格 | 请检查地址格式 |
| No.77 改为 No77、No. 77；6F 改为 F6；删去一个地址字段 | 请检查地址格式 |
| New Territories 改为 Old Territories；Hong Kong 改为 Hong Kang；Sha Tin 改为 Tai Po | 无效地址；地区段须为 Sha Tin, New Territories, Hong Kong |
| Flat A1 改为 Flat B2，其余相同 | 格式及地区通过，但与付款人留档不同。提示联系付款银行，可保存「银行复核中」，07:00 不提交 |
| 把收款人姓名清空或仅留空格 | 请填写收款人姓名 |
| 中大银行改为香港银行；或账号末位 1 改为 9 | 收款资料未能核实 |
| 账号改为 1234567（少于八位）、超过十六位、含空格、字母或全角数字 | 提示半角数字和长度要求 |
| 选香港手机号，把 90000001 改为 9000001、+85290000001 或全角号码 | 手机号须为八位半角数字 |
| 手机号改为 90000009，保持八位 | 此号码未取得可用收款登记 |
| 海湾银行付款总额由 5000 改为 10 或 5 | 付款总额须大于手续费 |
| 张三从空记录开始，输入 12,001 | 弹窗提示超过单笔额度；12,000 可预约 |
| 张三先预约 12,000，再预约 6,001 | 可用余额仅 6,000，弹窗提示余额不足 |
| 陈大文先预约 15,000，再预约 5,001 | 今日剩余额度仅 5,000，弹窗提示超出当日剩余额度 |
| 输入 24:00 或 07:60 并确定 | 时间格式提示，继续使用上次已确认的时间 |
| 在 01:00 打开核对页，确认前输入并确认 02:00 | 旧报价过期，显示新旧实收，点击「接受本小时新报价」后才能确认 |
| ZHANGSAN → 张三、ZhangSan 或 ZHANG SAN；CHENDAIWEN → CHEN DAIWEN | 需要全部大写并无空格 |
| ZHANGSAN → ZHANGSI | 英文姓名与档案不匹配 |
| Kevin James → kevin  james | 允许大小写和多余空格，其他资料正确即可通过 |
| Kevin James → Kevin Jones | 提示核对英文姓名拼写 |
| 张三的证件从大陆居民身份证改成护照 | 证件类型不匹配 |
| 大陆身份证少一位；香港身份证去掉括号；护照少一位；清空证件号 | 检查证件号码格式 |
| 保持证件格式，将示例号码内的一位数字改成其他数字 | 证件号码与档案不匹配 |
| 每位收款人分别选 HKD 和 CNY，使用同一正确账户 | 六种组合均可预约。CNY 同币种汇率为 1，HKD 使用所选银行当小时的汇率 |
| 账户或手机号换成另一名有效收款人的号码，保留原姓名和证件 | 档案交叉匹配失败，即使每个字段单独看都有效 |
| 错填后改回正确值，再次核对并预约 | 07:00 确认中，07:05 已到账，11:00 无订单 |
| 仅保存地址待复核申请，推进到 07:05 | 无有效订单，待复核申请不会扣款 |
| 同时预约两笔，仅对其中一笔发送暂停入账通知 | 07:05 两份回执结果不同，11:00 只展示退汇的那笔 |
| 连续查询原交易，或回拨再推进时钟 | 沿用原编号，扣款及提交次数不增加 |
| 选择清空记录后点取消；再次选择并确认 | 取消后仍可查询；确认后 07:05 无有效订单，11:00 无订单 |

地区按大小写精确匹配；若同时破坏标点并改动地区，先显示格式提示。该地址模板和额度是本项目的教学设定。三位收款人均可选择 HKD 或 CNY，适用同一时间线。
